## 0. Headline

**Do not bump `lastVerified` yet. 0.65.0 has three breakages besides #904, and each needs a code change.**

0.65.0 adds a theme of **"refuse instead of clobbering a live thing unless `--force`"**. #904 covered
one instance of it (`close-surface`). The same change lands in three more places squadrant depends on:

| | Breakage | squadrant path | Effect on 0.65.0 |
|---|---|---|---|
| **B1** | `send` refuses text into an agent prompt that holds a draft | `sendToSurface` #302 backspace probe, `real-draft` branch: restores the removed grapheme with `cmux send` | The restore is refused. The **captain's draft loses its last character on every probe cycle**, and repeated cycles can eat the whole draft (#258 class). Only affects the pane-fallback delivery path. |
| **B2** | `send-key` refuses keys into an open agent question/permission dialog | `squadrant crew answer` (#592), which drives arrows + Enter into the dialog on purpose | `crew answer` fails for every cmux-tracked agent pane (claude confirmed; codex also recognised by cmux). The remote-answer flow (#486) is broken. |
| **B3** | `workspace close` refuses a workspace with a running process | `CmuxRuntime.stop()`: bare `workspace close`, errors swallowed | Stopping a live captain workspace (`launch --fresh`, etc.) **fails silently** and the workspace stays open. #904 fixed only `closePane`. |

Everything else squadrant calls is unchanged or changed additively (§1). Events stream, hook store,
`tree`/`workspace list` JSON and every summary line squadrant parses keep their shape **[V]**.

### Breakage detail

**B1: the probe restore (row 4a).** `sendToSurface` (`runtimes/cmux.ts`, `real-draft` branch, plus
the trailing-space branch of `inconclusive`) sends `backspace` (allowed: `.key`, no dialog) and then
`cmux send … <lastGrapheme>` to put the character back. On 0.65.0 the prompt still holds the rest of a
multi-character draft, so cmux reports `state: draft, blocks_typing: true` and the restore throws
`the agent prompt in … holds text someone is typing, so nothing was sent`. The removed character is
gone. The throw is not a `DeferDelivery`, so `CaptainDelivery` records an `unknown` defer. The draft
is now one character shorter, so the stability counter resets, and after `stableProbePolls` polls
the probe runs again and removes another character. **Exposure:** only when captain delivery falls
back to the pane (`captainChannel` off/shadow, a captain without a peer socket, the opencode
fallback). `captainChannel: on` is the default since #887, which limits but does not remove it.

**B2: `crew answer` (row 5a).** cmux classifies a screen as `dialog` when one of the bottom six
non-empty rows contains `esc to cancel` / `esc to go back` / `press enter to` / `enter to confirm` /
`enter to select`. Claude's AskUserQuestion and permission dialogs show these hints. With
`"agent": true` (confirmed for squadrant's claude panes), every `send-key Down/Up/Left/Right/Enter`
from `crew-answer.ts` is refused, so `crew answer` cannot drive the dialog. Free-text answers
(`pasteToPane` after picking "Type something") hit the row-4 guard as well.

**B3: workspace stop (row 3).** `stop()` swallows every error from `workspace close`, so the refusal
is completely silent. The workspace and its captain keep running while the caller believes it is
closed.

## 2. What to bump in `packages/shared/src/lib/compat-manifest.ts`

**Not in this change.** Once B1–B3 are fixed (and #904 merged):

```diff
- cmux:     { min: "0.64.0",  lastVerified: "0.64.22" } satisfies ToolEntry,
+ cmux:     { min: "0.64.0",  lastVerified: "0.65.0" } satisfies ToolEntry,
```

- **Do not raise `min`.** The `--force` flags on `close-surface` / `send` / `send-key` / `workspace close`
  are new in this window. Older cmux builds may reject the unknown flag (`close-surface --force` on
  0.64.x is unverified), so the B1–B3 fixes and #904 need to either check the version or tolerate the
  failure on older builds. Raising `min` to `0.65.0` instead would be a deliberate floor decision for
  the captain.
- **No test pins the manifest value.** `packages/shared/src/lib/__tests__/tool-compat.test.ts:87`
  passes an inline `{ min, lastVerified: "0.64.22" }` object and does not import `compatManifest`.
  The other `0.64.22` mentions are comments in `runtimes/cmux.ts` (lines 91, 102, 702, 714, 777)
  and `cmux-daemon/events-bridge.ts` (17, 57); re-date them with the bump.
- **Agent entries unchanged, per the brief.** Installed here: `claude 2.1.294` (manifest has only
  `min: 2.1.32`, no `lastVerified`, so there is nothing to compare against and no warning) and
  **`codex`, which is also installed**, contrary to the brief. Neither `gemini` nor `opencode` is
  installed. `codex`/`gemini`/`opencode` keep their entries untouched; this study did not audit them.

## 5. Method / reproducibility

**Call-site inventory.** `grep` over `packages/**/src` (excluding tests and dist) for `cmux([…])`,
`execFile*(resolveCmuxBin(), …)` and the events-bridge argv. That gives 20 verb/flag combinations
across `runtimes/cmux.ts`, `cmux-daemon/events-bridge.ts`, `notifiers/cmux.ts`, `shared/lib/cmux-probe.ts`,
`cli/commands/{launch,command,dashboard}.ts`. Every one is covered by a row above.

**Source diff [S].** As in the 0.64.22 study, nothing was cloned:

```bash
for t in v0.64.22 v0.65.0; do
  gh api "repos/manaflow-ai/cmux/git/trees/$t?recursive=1" \
    --jq '.tree[] | select(.type=="blob") | .path + " " + .sha' > tree-$t.txt
done
gh api repos/manaflow-ai/cmux/git/blobs/<sha> --jq .content | base64 -d > cmux-<tag>.swift
```

Each dispatch-level `case "<verb>":` block in `CLI/cmux.swift` (`3faf000b…` → `f3c68535…`) was
extracted and diffed per verb. Also read: `CLI/CMUXCLI+Paste.swift` (guard, `--force`/`--paste`),
`Sources/TerminalController+SurfaceInputState.swift` (`e5a5e278…`),
`Packages/macOS/CMUXAgentLaunch/Sources/CMUXAgentLaunch/AgentPromptInputState.swift` (`3febb4e2…`).

**Live probes [V].** Read-only: `--version`, `workspace list --json --id-format refs`,
`current-workspace`, `capabilities`, `cmux rpc surface.input_state` on this crew's **own** surface,
`cmux events --after <cursor-5> --limit 3`, the hook-store JSON keys, and the daemon's
`cmux events` process and cursor file. Mutating probes ran **only** inside a throwaway workspace this
audit created (`workspace create --command "sleep 600" --cwd <scratch>`; default `--focus false`):
`workspace rename`, `tree` (text and JSON), `rename-tab` (positional and `--title`),
`workspace-action pin/unpin`, `tab-action pin`, `new-surface`, `new-pane`, `send`/`send-key`/`read-screen`
with and without `--surface`, `close-surface` (idle, stale ref, blank `--workspace`, live process,
`--force`), `workspace close` (refused), then `workspace close --force`. Every `close-surface` call
named an explicit `--surface`. Afterwards the workspace was no longer listed and its `sleep 600`
process was gone. The draft/dialog guards (B1/B2) were confirmed from source plus `"agent": true`
on a live squadrant claude pane. They were not triggered live, because that needs a throwaway
*agent* pane in a draft or dialog state.
